# Value catalog

The reproducible [topic catalog](topic-catalog.csv) lists supported source/profile
properties, wire suffixes, units and channel groups. It is generated from runtime
constructors and bundled mappings, without installation configuration or captures.

See [topic groups](TOPIC_GROUPS.md) for classification and
[configuration](CONFIGURATION.md) for enable flags, units, retention and command
gates. Supported metadata does not establish live availability. Alternative source
rows do not imply duplicate active owners; editable metadata does not grant writes.
The public catalog deliberately contains no deployed Item names or live values.
